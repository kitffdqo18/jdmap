1. 수집 항목과 목적

수집 항목담당자명, 연락처, 이메일, 사업자등록번호, 회사명, 업종, 상시근로자 수, 매출액, 총급여, 문의 내용, 신청 시각
이용 목적기업중대재해배상책임보험 견적 산출 및 상담 연락

2. 보유 기간과 파기

신청일로부터 일 동안 보관한 뒤 지체 없이 파기합니다. 보험계약이 체결된 경우에는 관련 법령에서 정한 기간 동안 보관합니다. 전자 파일은 복구할 수 없는 방법으로 삭제합니다.

3. 처리 위탁 및 국외 이전

운영자는 신청 정보를 보관하고 알림 메일을 받기 위해 아래 서비스를 이용합니다. 이 외에 제3자에게 제공하지 않으며, 견적 산출을 위해 보험회사에 전달해야 하는 경우에는 사전에 별도로 동의를 받습니다.

수탁·이전 받는 자Google LLC (Google Workspace / Google 스프레드시트, Gmail)
이전 국가미국 등 Google 데이터센터 소재 국가
이전 시기·방법견적 신청 시 암호화된 네트워크(HTTPS)로 전송
이전 항목1항의 수집 항목 전체
보유 기간2항과 같음

사이트 화면은 GitHub Pages(GitHub, Inc.)에서 제공되며, 이 과정에서 접속 기록이 GitHub 에 남을 수 있습니다. 견적 신청 정보는 GitHub 에 저장되지 않습니다.

4. 정보주체의 권리

신청하신 분은 언제든지 본인 정보의 열람, 정정, 삭제, 처리 정지를 요청할 수 있습니다. 아래 연락처로 요청하시면 지체 없이 처리합니다.

5. 안전성 확보 조치

전송 구간 암호화(HTTPS), 신청 정보 보관 계정의 2단계 인증, 보유 기간 경과 정보 자동 파기를 시행합니다.
