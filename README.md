# 중대재해 MAP — 서버 없이 혼자 운영하기

전국 중대재해 3D 현황판과 기업중대재해배상책임보험 견적 신청을 받는 사이트입니다.
**서버를 빌리지 않고 무료 서비스만으로** 돌아갑니다.

| 하는 일 | 맡는 곳 | 비용 |
|---|---|---|
| 사이트 화면 (지도·현황판·보험 안내·Q&A·견적 폼) | GitHub Pages | 무료 |
| 하루 3번 사고 데이터 갱신 | GitHub Actions (예약 실행) | 무료 |
| 지도 경계(시도·시군구) 만들기 | GitHub Actions (버튼 한 번) | 무료 |
| 견적 신청 저장 + 알림 메일 | 내 구글 스프레드시트 + Gmail (Apps Script) | 무료 |
| 내 도메인 연결 (선택) | 도메인 업체 | 연 1~2만 원대 |

내 PC에서 미리 보려면 `docs/index.html` 을 더블클릭하면 됩니다.

---

## 1단계. GitHub 저장소 만들고 파일 올리기 (10분)

1. github.com 에 가입하고 로그인합니다.
2. 오른쪽 위 **+ → New repository** → 이름(예: `jdmap`) 입력 → **Public** 선택 → **Create repository**.
   - 무료 계정은 Public 저장소만 무료로 사이트를 열 수 있습니다. 코드와 사고 데이터는 공개되지만, **견적 신청 정보는 GitHub에 저장되지 않으니** 걱정하지 않아도 됩니다.
3. 새 저장소 화면에서 **uploading an existing file** 을 누르고, 압축을 푼 `jdmap-static` 폴더 **안의 내용 전부**를 끌어다 놓습니다 → **Commit changes**.
4. 올린 뒤 저장소에 `.github` 폴더가 보이는지 확인합니다.
   - 안 보이면(맥에서 숨김 폴더라 빠진 경우): **Add file → Create new file** 에서 파일 이름 칸에 `.github/workflows/collect.yml` 을 입력하고, 압축 안의 같은 파일 내용을 붙여 넣어 저장합니다. `build-geo.yml` 도 같은 방법으로 만듭니다.

## 2단계. 사이트 켜기 (3분)

1. 저장소 **Settings → Pages**.
2. Source: **Deploy from a branch**, Branch: **main**, 폴더: **/docs** → **Save**.
3. 1~2분 뒤 같은 화면 위쪽에 사이트 주소가 나옵니다. 예: `https://아이디.github.io/jdmap/`

## 3단계. 자동 갱신 권한 주기 (1분)

**Settings → Actions → General → Workflow permissions** 에서 **Read and write permissions** 를 고르고 **Save**.
(이걸 해야 예약 실행이 사고 데이터·지도 파일을 저장소에 저장할 수 있습니다)

## 4단계. 견적 접수용 구글 시트 만들기 (10분)

1. 구글 드라이브 → **새로 만들기 → Google 스프레드시트** (이름 예: 중대재해 MAP 접수).
2. 메뉴 **확장 프로그램 → Apps Script**.
3. 기존 내용을 지우고 `apps-script/Code.gs` 내용을 전부 붙여 넣고 저장(💾).
   - 맨 위 `CONFIG` 에서 알림 받을 주소(`NOTIFY_TO`)를 적습니다. 비우면 본인 Gmail 로 옵니다.
4. 위쪽 함수 선택 칸에서 **setup** 을 고르고 **실행** → 권한 확인 창에서 계정 선택 → '고급 → (안전하지 않음)으로 이동' → **허용**.
   - 본인이 만든 스크립트라 나오는 경고입니다. 끝나면 '접수 알림 설정 완료' 메일이 옵니다.
5. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴에서 **웹 앱** → 실행 사용자: **나**, 액세스 권한: **모든 사용자** → **배포**.
6. 나온 **웹 앱 URL**(…/exec 로 끝남)을 복사합니다.

시트의 `접수` 탭이 곧 접수함입니다. `상태` 칸은 신규 → 연락완료 → 견적발송 → 계약 → 종결 중에서 고르면 됩니다.
보유기간(기본 365일)이 지난 신청은 매일 새벽 3시에 개인정보 칸이 자동으로 '파기' 처리됩니다(계약 건 제외).

> Apps Script 코드를 고쳤다면 **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포** 를 해야 반영됩니다.

## 5단계. 사이트 설정 (2분)

GitHub 저장소에서 `docs/config.js` → 연필(✏️) 아이콘 → 아래를 채우고 **Commit changes**.

```js
leadEndpoint: "4단계에서 복사한 웹 앱 URL",
operatorName: "홍길동",
operatorEmail: "me@gmail.com",
```

1~2분 뒤 사이트에서 견적 신청을 직접 한 번 해 보세요. 알림 메일이 오고 시트에 한 줄이 생기면 성공입니다.

## 6단계. 지도 경계 만들기 (5분, 처음 한 번)

이 단계를 건너뛰어도 시도 지도는 기본 지도로 나옵니다. 다만 **시군구 단계**를 쓰려면 꼭 해야 합니다.

1. 원본 주소 구하기: 공개 행정동 경계 저장소(예: github.com/vuski/admdongkor)에서 **가장 최근 버전 폴더** → `.geojson` 파일 → **Raw** 버튼 → 주소창의 주소를 복사합니다.
   - 저장소 안내문의 **이용 조건·출처 표기**를 확인하고, 아래 3번의 출처 칸에 그대로 적습니다.
2. 내 저장소 **Actions → 지도 경계 만들기 → Run workflow**.
3. 원본 주소를 붙여 넣고, 출처 표기를 확인한 뒤 **Run workflow**.
4. 3~5분 뒤 초록 체크가 뜨면 `docs/geo/` 에 `kr-sido.js`, `kr-sigungu.js` 가 생기고 사이트에 반영됩니다.
   - 행정구역이 바뀌었을 때(새 버전이 나왔을 때)만 다시 실행하면 됩니다.
   - 빨간 X 가 뜨면 실행 기록을 눌러 마지막 오류 문장을 확인하세요. '시도가 N개뿐입니다'면 원본 파일 형식이 다른 것입니다.

화면 동작: 시도 클릭 → 솟아오름 → 한 번 더 클릭 → 시군구 지도 → 시군구 클릭 → 솟아오름 → 한 번 더 클릭 → 사고 상세 → `← 전국` 으로 복귀.

## 7단계. 사고 데이터 채우기

**A. 직접 등록 (바로 가능)**
`data/manual_incidents.csv` 를 GitHub에서 열고 ✏️ → 첫 줄 아래에 한 줄씩 추가 → Commit. 2~3분 뒤 반영됩니다.
```
게시일,발생일시,시도,시군구,업종,재해유형,사망,부상,제목,사고개요,원문링크,고유번호
2026-10-13,2026-10-12 14:30,,,,,,,,충청남도 당진시 소재 건설현장에서 근로자 1명이 떨어져 사망,,
```
게시일과 사고개요만 써도 시도·시군구·업종·재해유형·사망자가 자동으로 채워집니다. 엑셀로 편집했다면 'CSV UTF-8'로 저장해 올리세요.

**B. 사이렌 자동 수집**
`data/siren_config.json` 에 사이렌의 실제 데이터 주소를 넣고 `enabled` 를 `true` 로 바꾸면 하루 3번(07:30·12:30·18:30) 자동으로 가져옵니다.
데이터 주소는 크롬 개발자도구(F12 → Network → Fetch/XHR)에서 사이렌 목록을 불러오는 요청을 찾아 확인합니다. 그 요청 화면을 캡처해 Claude 에게 주면 설정 파일을 채워 줍니다.
- GitHub Actions 는 해외 서버에서 실행됩니다. 사이렌 사이트가 해외 접속을 막으면 자동 수집이 실패하니, 그때는 A 방식으로 운영하세요.
- 공단 게시물을 다시 게시해도 되는지 이용 조건을 확인하세요.

**C. 고치기·숨기기**
- 지역을 못 찾은 사고는 `data/unmapped.csv` 에 자동으로 정리됩니다.
- 그 줄을 `data/corrections.csv` 에 복사해 시도·시군구를 채우면 지도에 나옵니다.
- 숨기려면 `숨김` 칸에 `Y` 를 적습니다.
- 사고의 고유번호는 사이트 상세 창 오른쪽 아래에 있습니다.

## 8단계. 내 도메인 연결 (선택)

**Settings → Pages → Custom domain** 에 도메인을 넣고, 도메인 업체 DNS 에 GitHub 안내대로 레코드를 추가합니다. **Enforce HTTPS** 를 켜 둡니다.

- [ ] 회사 겸직 규정, 보험 광고·모집 관련 준법감시 기준
- [ ] 시험 신청 → 메일·시트 확인 → 시험 행 삭제
- [ ] 구글 계정 2단계 인증 켜기 (접수 정보가 이 계정에 저장됨)

## 평소 운영

| 할 일 | 방법 |
|---|---|
| 새 견적 확인 | 알림 메일 → 시트 링크 |
| 갱신이 돌았는지 | 저장소 **Actions** 탭 (초록 체크) / 사이트 상단 'OO:OO 갱신' 표시 |
| 지금 바로 갱신 | Actions → 사고 데이터 갱신 → Run workflow |
| 예약 실행이 멈췄을 때 | 저장소에 60일간 변경이 없으면 GitHub 가 예약을 멈출 수 있음 → Actions 탭에서 다시 켜기 |

## 폴더 구성

```
docs/                사이트 (GitHub Pages 가 그대로 보여 줌)
  index.html         현황판·지도·보험 안내·Q&A·견적 폼
  privacy.html       개인정보 처리방침
  config.js          설정 (접수 주소, 운영자 정보)
  data/incidents.js  사고 데이터 (자동 생성)
  geo/               지도 경계 (6단계에서 자동 생성)
data/                직접 고치는 입력 파일 (data/README.txt 참고)
tools/               갱신 프로그램 (수집·지역 분류·지도 변환)
apps-script/Code.gs  견적 접수 (구글 시트에 붙여 넣는 코드)
.github/workflows/   예약 실행 설정
tests/               테스트 (python -m unittest discover -s tests / node tests/test_apps_script.js)
```
