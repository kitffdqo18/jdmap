이 폴더 파일을 GitHub 화면에서 고치면 2~3분 뒤 사이트에 반영됩니다.

manual_incidents.csv  사고 직접 등록. 첫 줄(열 이름)은 그대로 두고 아래에 한 줄씩 추가.
                      게시일과 사고개요만 써도 됨 (지역·업종·유형·인원은 사고개요에서 자동 추출)
corrections.csv       잘못 분류된 사고 고치기 / 숨기기. 고유번호는 사이트 상세 창 오른쪽 아래에 표시됨.
                      숨기려면 '숨김' 칸에 Y
unmapped.csv          지역(시도)을 못 찾은 사고 목록 (자동 생성). 이 내용을 corrections.csv 에 복사해 시도를 채우면 됨
siren_config.json     안전보건공단 중대재해 사이렌 자동 수집 설정 (안내서 7단계)
